# Sorting Visualizer

An interactive web app that visualizes how the Bubble Sort algorithm works, step by step.

## Why I built this
I wanted to practice algorithmics and data structures by turning an abstract sorting algorithm into something visual. Each comparison and swap is animated so you can watch the array slowly become sorted.

## How to run it
Open `index.html` in any web browser.
